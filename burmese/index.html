Burmese script descended from the ancient Mon script (Southeast Asia's writing family), distinctive with circular, curvy letter shapes. The script evolved by the 11th-12th centuries into its modern Burmese form. Burmese is left-to-right and fully phonetic with 33 consonant letters organized in historically standardized groupings. The script uses floating tone marks and diacritics positioned above and below base letters — not inline like Latin or Arabic. Unicode support for Burmese was finalized in the international standard, but adoption was delayed — major platform pushes (Google, Facebook, Viber) didn't occur until 2019 onward. The Zawgyi/Unicode incompatibility is Burmese's defining modern technical problem — a non-standard encoding that still dominates legacy systems, creating invisible communication barriers.

The critical technical challenge is Zawgyi vs Unicode — two incompatible encoding systems exist in active use simultaneously. Zawgyi (legacy, pre-Unicode) is still dominant on older devices/software; Unicode (international standard) is modern. Text sent in Zawgyi appears as garbled boxes on modern phones; Unicode renders perfectly. Burmese vowels use a combining mark system (floating diacritics above/below consonants, not inline).
