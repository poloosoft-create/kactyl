Calligraphy Questions

What is the difference between a calligraphy font and real calligraphy?

A font has fixed letter shapes that are reused everywhere; a calligrapher redraws every stroke to suit one phrase. These generators shape real font files, which covers names, invitations, logos and posts — but a font will never make the compositional decisions a human calligrapher makes.

How is this different from the other free generators?

Most of them substitute lookalike Unicode characters, so the result is not really your script and often breaks when pasted. These pages load actual font files and shape them properly, which is why joined Arabic joins and Bengali conjuncts form instead of falling apart into separate letters.

Can I export a file for printing?

Yes. Alongside PNG you can export SVG and PDF, which are true vector outlines — they stay sharp on a wedding card, a book cover or a shop sign. Most free tools only hand you a fixed-size image.

Do I need a keyboard for that language?

No. Paste text from anywhere, or type a name in English letters and let the built-in transliterator convert it. If you do want to type properly, there is a full keyboard for each of these languages elsewhere on the site.

Are the fonts free to use commercially?

They come from Google Fonts under open licences that permit commercial use, including on products you sell. Check the individual licence if a client wants it confirmed in writing.

Why do some scripts have far more styles than others?

Because that is how much type design each script has attracted. Arabic and Devanagari have decades of digital type behind them; Bengali has ten faces on Google Fonts that both apply correctly and form conjuncts. Every style listed here was checked in a browser first, and none was added just to make a number look bigger.

Which script should I start with?

Pick the one your text is actually in — these are different writing systems, not styles of one another. Arabic and Urdu share letterforms but Urdu leads with Nastaliq; Hindi, Gujarati and Bengali share a Brahmi ancestor but no fonts.
