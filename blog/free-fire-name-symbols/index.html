Which Symbols Do NOT Work in Free Fire

Some characters cause issues in FF names:

  • Emoji (🔥 👑) — display as blank boxes in most regions
  • Arabic Presentation Forms — some older Unicode Arabic blocks render incorrectly; use standard Arabic Unicode instead
  • Zero-width characters — Free Fire strips invisible characters from names
  • Combining diacritics stacked 3+ deep — can overflow the name display box

Do These Symbols Work in PUBG Mobile?

Yes — all Unicode symbols and border templates on this page work in PUBG Mobile names exactly the same as in Free Fire. Both games render Unicode characters natively.

The key difference: PUBG Mobile has a 16-character limit vs Free Fire's 20. When using border templates, choose shorter ones like NAME or ★NAME★ rather than longer decorative strings to stay under the limit.
