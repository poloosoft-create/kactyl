Bijoy, Avro and UniBijoy — the split that decides your speed

Bengali typing carries a division that most scripts never had to deal with: the same keyboard layout can produce two completely different kinds of text.

Bijoy, developed by Mustafizur Rahman at Ananda Computers, became the de facto standard in Bangladesh and is still the layout used across government offices, courts and educational institutions. It is what the Bangladesh Public Service Commission expects in BCS cadre typing tests, and what NTRCA teacher-registration exams require. Bijoy output is ANSI — legacy encoding — so it needs its matching font installed to display as Bengali at all.

Avro, from OmicronLab, went the other way: phonetic input producing Unicode. You type amar and get আমার. It is the reason Bengali became usable on the open web, because Unicode text renders anywhere without shipping a font alongside it.

UniBijoy is the bridge, and it is the practical answer for most people caught between the two. It keeps Bijoy's key positions exactly — so decades of muscle memory still work — while emitting Unicode. Typists who learned Bijoy for an exam can move to modern software without relearning the board.

In India, West Bengal government work more often uses the InScript Bengali layout, which shares its logic with the other Indian InScript layouts rather than with Bijoy.

This test measures Unicode Bengali, so Avro, UniBijoy and InScript all work here directly. Classic Bijoy does not, because the characters it produces are not Bengali as far as any Unicode-aware program is concerned.

Settle the layout question before you practise anything

Bengali is the one language here where practising before deciding is actively wasteful. Bijoy and Avro are not two roads to the same place: one trains finger positions for individual letters, the other trains you to spell in Latin and let an engine convert. Hours in Avro build almost no Bijoy muscle memory. If an exam is in your future, find out which layout it names first, and spend your practice there.

Once that is settled, the drill that matters in Bangla is juktakkhor. Look at the missed-character list after a run — it will be dominated by হসন্ত sequences and by the dotted pairs ড় ঢ় য়. Those dotted letters deserve special attention because the failure is invisible: the word looks right on screen and compares as wrong, so you can practise a mistake for weeks without noticing it.

Two minutes is the right length once you are past the beginner stage. Bengali words in this list run long, and a fifteen-second burst rewards guessing where a two-minute run punishes it.

What Bangla typing exams are actually testing

The thing worth knowing before you practise: BPSC and NTRCA typing tests are layout tests as much as speed tests. They specify Bijoy, and a candidate who is fast in Avro phonetic can be slow to the point of failing on a Bijoy board, because phonetic typing never trains finger positions for individual Bengali letters at all — the engine does the spelling.

If an exam is your reason for practising, find out which layout the exam specifies before you put hours into any of them. If you are typing for work, email or writing, the Unicode question matters more than the layout question: text that is not Unicode cannot be searched, cannot be copied into a web form, and will not survive being sent to somebody who does not have your font.

This test is useful for the second case, and for building raw speed and accuracy in the first. It is not a Bijoy simulator.

The characters Bangla typists lose time on

্

Hasanta and the juktakkhor

ক্ষ, ঞ্চ and স্ত are single shapes built from three keystrokes each. Hasanta is the join. Miss it and you get two loose letters that look almost right and compare as wrong.

ড়

The dotted pair

ড় ঢ় য় each exist as one codepoint and as base-plus-nukta. Identical on screen, different as data. This is the single most common source of a "correct" word being marked incorrect.

ি

The vowel that appears first

কি shows ি to the left of ক but is typed after it. In Bijoy you type it in visual order; in Unicode you type it in logical order. Switching systems inverts the habit.

ং

Anusvara against ঙ

বাংলা uses ং, not ঙ. They read similarly and sit in different places on every layout.

FAQ

Frequently Asked Questions

How is speed measured here?
Whole words typed correctly per minute, with visual letter units per minute shown beside it. On this word list that convention would report roughly 1.7 times the words-per-minute figure shown here, because it counts the keystrokes hidden inside conjuncts as if they were separate letters.
Can I take this test with the Avro keyboard?
Yes. Avro produces Unicode Bengali, which is exactly what this test reads. Type as you normally would.
Does Bijoy work here?
Classic Bijoy does not — it outputs ANSI, not Unicode, so the page receives Latin characters rather than Bengali. UniBijoy has the same key positions and does work, because it emits Unicode.
Do I need Bengali installed to take the test?
No. The on-screen Bengali keyboard below the test is the key grid from our Bengali keyboard page and you can click through it.
Why is my Bangla speed lower than my English speed?
A word in this list averages 2.53 visual units and 4.21 codepoints — 91% of them contain at least one cluster that takes more keystrokes than it shows. More work per finished word.
Where do the words come from?
A Bengali frequency corpus, the same verified list our Bengali keyboard autocompletes from. Not hand-written.
Does it handle juktakkhor correctly?
Yes, and that is most of the point of building this separately from an English typing test. ক্ষ counts as one visual unit, not three, because that is what it is.
Is this useful for BCS typing preparation?
For speed and accuracy, yes. For the exam itself, only if you confirm the layout it requires — BCS specifies Bijoy, which this test cannot read.
What is the longest word in the test?
সবসময়, at 5 visual units.
Does it work on a phone?
Yes, with your phone keyboard, which will normally be phonetic.
Is my score stored anywhere?
Only in your own browser. Nothing is sent to us.
Is Bangla the same as Bengali here?
Same language, two names for it. The test is the same either way.
