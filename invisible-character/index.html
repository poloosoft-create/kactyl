About Invisible Characters

Invisible characters are real Unicode characters that take up space (or no space) in text but render as completely blank to the human eye. They're not spaces — they're distinct Unicode codepoints with specific technical purposes, which is why they bypass filters that block regular spaces in usernames, bios, and message fields.

The most popular invisible character for gaming is the Hangul Filler (U+3164) — a full-width blank character from the Korean Hangul Unicode block that was originally used as a placeholder in Korean text processing. Games like PUBG Mobile, Free Fire, and Roblox allow Hangul Filler in usernames because it passes their character validation as a legitimate Unicode character, making your name appear completely blank to other players.

For messaging apps like WhatsApp and Telegram, a Non-Breaking Space (U+00A0) or Zero Width Space (U+200B) sends a "blank" message that doesn't trigger the empty-message check. For Instagram and TikTok bios, the Braille Pattern Blank (U+2800) creates invisible line spacing without the platform collapsing the empty lines. Each platform has quirks — which character works depends on how the platform validates input.

Frequently Asked Questions

How do I send a blank WhatsApp message?
Copy the Non-Breaking Space (U+00A0) from this page using the WhatsApp button in the platform section above, paste it into your WhatsApp message field, and press send. WhatsApp validates that a message has content — this Unicode character registers as content while appearing completely blank to the recipient. You can also use Hangul Filler (U+3164) as an alternative.
Which invisible character works for PUBG and Free Fire names?
The Hangul Filler (U+3164) is the most reliable for PUBG Mobile, Free Fire, and similar mobile games. Use the platform buttons above or the generator to create 3 characters at once. If a single character is rejected, try pasting 3–5 Hangul Fillers. The Braille Pattern Blank (U+2800) works as an alternative if Hangul Filler is blocked.
How do I get an invisible Discord nickname?
Copy the Zero Width Space (U+200B) using the Discord button above, then go to your Discord server, right-click your name, choose "Edit Server Profile," and paste it as your nickname. You will appear as a blank name in the member list. Note that server admins can see that a nickname is set even if it looks invisible.
What is the best invisible character for Roblox?
Hangul Filler (U+3164) works in Roblox display names. Copy 2 characters using the Roblox button above and paste them into your display name field in Settings. Your character will appear nameless to other players. Note that Roblox username changes may have cooldowns — display names can be changed more freely.
How do I add blank lines to my Instagram bio?
Use the Braille Pattern Blank (U+2800) — copy it using the Instagram button above. In your Instagram bio, go to the line you want to appear blank, and paste the character there. Instagram will not collapse this line like it does with regular empty lines, giving you clean visual spacing between bio sections. One character per blank line is enough.
Can I use invisible characters on TikTok?
Yes. Braille Pattern Blank (U+2800) works in TikTok display names and bios. Use the TikTok button in the platform section above. Paste it in your TikTok nickname field (Profile → Edit Profile → Name) to create a blank-looking username, or use it in your bio on empty lines to create invisible spacing between sections.
Is using invisible characters allowed in games?
Most games do not explicitly ban invisible character usernames since they pass standard Unicode character validation. Game policies vary — some games may reset blank usernames in future updates. Using invisible characters in usernames is widespread and generally tolerated, but check your specific game's terms of service if you are concerned about account safety.
Do invisible characters work on both mobile and PC?
Yes. Invisible characters are standard Unicode characters that work on all devices — Android, iPhone, Windows, Mac, and Linux. They are part of the Unicode standard so they render (or do not render) identically on all platforms. Copy from this page on any device and paste anywhere.
Can I hide a secret message using invisible characters?
Yes — use the Secret Message Encoder section on this page. Type your message, click "Hide Message," and you get invisible text that looks completely blank but contains your encoded message. Anyone who pastes it into the Reveal tab on this page can recover the original text. The encoding works by converting each character to a 21-bit binary sequence using zero-width Unicode characters.
Why doesn't copy-paste work when I try to copy an invisible character manually?
Invisible characters cannot be selected by eye — you cannot see where they are to click or double-click them. The copy buttons on this page use the Clipboard API to programmatically copy the exact Unicode character to your clipboard, ensuring you get the right character every time without accidentally missing it or copying surrounding whitespace.
What is the difference between a space and an invisible character?
A regular space (U+0020) is filtered out by most platforms' empty-field checks — you cannot send a WhatsApp message with only spaces, and most games reject usernames containing only spaces. Invisible Unicode characters like U+3164 (Hangul Filler) and U+200B (Zero Width Space) are completely different codepoints that pass these filters because platforms do not recognize them as spaces. They look identical but behave differently technically.
How many invisible characters do I need for a PUBG invisible name?
Usually 1–3 Hangul Filler characters (U+3164) are enough for PUBG Mobile. Use the generator on this page: set the count to 3, select Hangul Filler, click Generate and Copy, then paste into your PUBG username field. If that is rejected, try 5 characters. The exact number accepted varies by game version and region server.
