In-depth look at each tool

What each tool does well, and what it does not have.

Kactyl
kactyl.com
Best for
Phones & sharing
62 live keyboards
The phone-first keyboard with voice, suggestions and sharing
Kactyl is built for typing on a phone and sending the text on. Every keyboard has word and next-word suggestions, an emoji panel with ready-made combos, a live character counter, voice input in every language your browser can recognise, and one-tap sharing to WhatsApp, Telegram, X, Facebook, Instagram, TikTok and Snapchat. You can also search your text on Google, YouTube or ChatGPT in one tap. On a computer, your real keys follow the official layout of each language that has one (InScript, Kedmanee, IRCAM, M.B. Sindhi).

It has 62 live keyboards today, with 300+ in progress, plus typing engines for Korean, Japanese, Chinese and Egyptian hieroglyphs, AI tashkeel for Arabic, and 14 text tools such as fancy text, symbols, kaomoji and calligraphy. No ads.
✓ Voice input ✓ Word suggestions ✓ Share to 7 apps ✓ 14 text tools ✓ No ads ✗ Fewer languages today
Lexilogos
lexilogos.com
Best for
Most languages
187 keyboards
The veteran multilingual resource, online since 2002
Lexilogos has the biggest keyboard collection of the four: 187 language keyboards plus variant pages, including many ancient and rare scripts such as Egyptian hieroglyphs, Phoenician, Coptic and Adlam. It goes beyond keyboards, with dictionaries, converters and transliteration tools.

Its keyboards show the Latin letter on each key and have Copy, Save as .txt and Dark mode. The pages fit on a phone, and the site has no ads. It has no voice input, word suggestions, emoji or sharing buttons.
✓ Most languages ✓ Ancient scripts ✓ Dictionaries ✓ No ads ✗ No voice input ✗ No sharing
Gate2home
gate2home.com
Best for
African languages
129 keyboard pages
A broad keyboard site with typing by sound
Gate2home lists 129 keyboard pages (the site says 170+ languages), including 30+ African languages and old scripts such as runes, Gothic and Ogham. You can type on your own keyboard, or type a word by sound (salam → سلام) and pick from ranked spellings.

It has dark mode, Copy, Download, an emoji keyboard, translate and Google search. On a phone, video ads fill the first screen and the keyboard loads after a tap. It has no voice input and no sharing to social apps.
✓ 30+ African languages ✓ Type by sound ✓ Dark mode ✗ Video ads ✗ No voice input
Branah
branah.com
Best for
Quick layouts
~98 keyboards
Simple layouts with the Latin letter on each key
Branah has about 98 language keyboards, with QWERTY and AZERTY options and the Latin letter printed on each key, so you can find letters fast. It fits on a phone and has Copy, Undo, Save, an emoji key, a Tweet button and Google search.

Beyond keyboards it offers text converters and a Braille translator, and it has an Android app. It has no dark mode, no voice input and shows ads.
✓ Latin letter on keys ✓ Text converters ✓ Android app ✗ No dark mode ✗ Ads
